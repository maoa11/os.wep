لوحة تحكم الموقع

سجّل الدخول لتعديل محتوى موقعك.

أول مرة تدخل؟ اتبع هذي الخطوات مرة واحدة فقط:
  1. افتح صفحة إنشاء المفتاح في GitHub
  2. في Repository access اختر Only select repositories وحدّد مستودع موقعك
  3. في Permissions افتح Repository permissions واجعل Contents = Read and write
  4. اضغط Generate token وانسخ المفتاح
  5. الصقه بالأسفل — يُحفظ في متصفحك أنت فقط، ولا يُرسل لأي جهة أخرى
يُخزَّن في هذا المتصفح فقط. تقدر تلغيه من GitHub في أي وقت.
